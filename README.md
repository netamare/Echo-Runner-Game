# Echo Runner 🎮

Echo Runner is a simple endless runner with a twist: **your previous runs come back as echoes**.

Every time you fail, your previous movement is recorded. On the next run, your echo repeats what you did before, so you have to avoid both the obstacles and your own past.

## Features

* Echoes that replay previous runs
* Endless gameplay
* Increasing difficulty
* Coins and scoring
* Lives and high score
* Pause and restart
* Help / How to Play page
* High score saved locally
* Responsive design

## Built With

* React
* TypeScript
* CSS

Have fun—and try not to get caught by your past! 👻
